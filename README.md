# Sprint 11 · Análisis de datos con Power BI e indicadores

Informe de Power BI con indicadores clave (KPI), medidas DAX y visualizaciones para analizar el rendimiento de ventas, transacciones y comportamiento de usuarios de una empresa de venta de productos online, organizado en 3 niveles de profundidad.

## Fuente de datos

Base de datos MySQL creada en el Sprint 2 (`db_proyecto`, tablas `transactions`, `companies`, `products`, `transaction_product`, `users`).

## Niveles del informe

- **Nivel 1** — KPIs y medidas DAX de facturación, ventas mensuales y empresas por país, con tabla de usuarios (media de transacciones en euros y dólares).
- **Nivel 2** — Tendencia mensual de ventas 2018-2019 y panel específico de análisis del mercado alemán.
- **Nivel 3** — Comportamiento de compra por usuario (productos, gasto, geolocalización), relacionando transacciones, usuarios y productos.
